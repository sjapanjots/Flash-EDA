# FlashEDA logo

The mark is a grid of sampled data points; the points inside a lightning bolt
light up: a quick sample of the data reveals the picture.

| File | Use |
|---|---|
| `flasheda-mark.svg`, `flasheda-mark-{128,256,512}.png` | the icon: avatars, docs, app icons |
| `flasheda-mark-small.svg`, `flasheda-mark-small-32.png`, `favicon.ico` | 48 px and below, where the dots would blur |
| `flasheda-logo-light.svg` / `.png` | icon + name on light backgrounds |
| `flasheda-logo-dark.svg` / `.png` | icon + name on dark backgrounds |
| `flasheda-social.svg` / `.png` (1280×640) | GitHub social preview, link cards |

Colours: navy `#0B1220` → `#16233D`, amber `#FDE047` → `#F59E0B`, grid points
`#475569`. Typeface: Inter Display Bold (converted to outlines, so the SVGs
need no fonts).

Keep the mark on its navy tile, don't recolour the bolt, and use the small
mark below 48 px.
